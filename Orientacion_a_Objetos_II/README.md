Para ejecutar desde la raíz del repositorio:

```sh
cd Orientacion_a_Objetos_II/Grupo11_Monitoreo
python3 -B main.py --demo
python3 -B -m unittest discover -s tests -v
```

En Windows se puede usar `py -3` en lugar de `python3`.
